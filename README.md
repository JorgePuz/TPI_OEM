# Trabajo Práctico Integrador - Organizacion Empresarial

Objetivo

Automatizar el proceso de solicitar vacaiones mediante un chatbot de telegram desarrollado con python


Tecnologias Utilizadas



BPMN 2.0 → modelado del proceso de negocio.

GitHub → control de versiones y almacenamiento del proyecto.

Visual Studio Code → entorno de desarrollo utilizado.

Funcionalidades
Solicitud de vacaciones.
Consulta de saldo disponible.
Validación de empleados.
Gestión de estados.
Manejo de errores.
Persistencia mediante archivos json

Ejecución

Ejecutar:
python bot.py
