# Trabajo Práctico Integrador - Organizacion Empresarial

Objetivo

Automatizar el proceso de solicitar vacaiones mediante un chatbot de telegram desarrollado con python


Tecnologias Utilizadas

Python 3.14 → lenguaje de programación principal.
Telegram Bot API → plataforma utilizada para interactuar con Telegram.
python-telegram-bot → biblioteca para desarrollar el chatbot.
Pandas → lectura y manipulación de datos del archivo Excel.
OpenPyXL → acceso y actualización de archivos Excel (.xlsx).
Microsoft Excel → base de datos simulada para almacenar empleados y días de vacaciones.
BPMN 2.0 → modelado del proceso de negocio.
GitHub → control de versiones y almacenamiento del proyecto.
Visual Studio Code → entorno de desarrollo utilizado.

Funcionalidades
Solicitud de vacaciones.
Consulta de saldo disponible.
Validación de empleados.
Gestión de estados.
Manejo de errores.
Persistencia mediante archivo Excel.

Ejecución
Instalar dependencias:
pip install -r requirements.txt
Ejecutar:
python bot.py
